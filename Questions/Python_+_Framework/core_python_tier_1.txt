What is difference between list and tuple?

| Feature          | List                                                  | Tuple                               |
| ---------------- | ----------------------------------------------------- | ----------------------------------- |
| Mutability       | Mutable                                               | Immutable                           |
| Syntax           | [1, 2, 3]                                             | (1, 2, 3)                           |
| Modification     | Can modify elements                                   | Cannot modify elements              |
| Add/remove items | Yes                                                   | No                                  |
| Methods          | More methods such as append(), remove(), sort()       | Mainly count(), index()             |
| Hashable         | No                                                    | Yes, if all elements are hashable   |
| Dictionary key   | Cannot be a key                                       | Can be a key if hashable            |
| Typical use      | Dynamic collection                                    | Fixed collection / record-like data |


what is difference between dict and set?

| Feature     | Dictionary            | Set                             |
| ----------- | --------------------- | ------------------------------- |
| Stores      | Key-value pairs       | Unique values                   |
| Example     | {"id": 101}           | {101, 102, 103}                 |
| Duplicates  | Keys must be unique   | Elements must be unique         |
| Lookup      | By key                | By value/member                 |
| Mutable     | Yes                   | Yes                             |
| Hashing     | Keys must be hashable | Elements must be hashable       |
| Typical use | Mapping/association   | Uniqueness & membership testing |

What is the difference between is and ==?

== → checks value equality
is → checks object identity — whether both variables refer to the same object in memory
A common interview trap

You may see:

a = 10
b = 10

print(a == b)  # True
print(a is b)  # Usually True

Python may reuse/cache certain immutable objects such as small integers and some strings
