# 🐍 Python Basic to Advanced

A structured **Python learning and practice repository** covering Python fundamentals, advanced concepts, Object-Oriented Programming, functions, exception handling, file handling, serialization, data structures, algorithms, concurrency, logging, and practical programming exercises.

This repository is created as a hands-on learning resource to strengthen Python fundamentals, improve problem-solving skills, and prepare for **Python Developer / Backend Developer interviews**.

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/shrikant-mane/Python_Besic_Advance.git
```

## 2. Navigate to the Repository

```bash
cd Python_Besic_Advance
```

## 3. Create a Virtual Environment

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

## 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## 5. Run Python Programs

For example:

```bash
python main.py
```

You can also execute individual examples:

```bash
python OOPS/inheritance.py
```

or:

```bash
python Sort_Algorithms/Bubble_Sort.py
```
