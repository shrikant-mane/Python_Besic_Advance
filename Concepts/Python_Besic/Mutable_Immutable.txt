=========================
Why Are Immutable Objects Useful?

Immutability gives several benefits.

1. Predictability
An immutable object cannot unexpectedly change.

2. Safer sharing
Multiple parts of a program can safely reference the same immutable object.

3. Hashability
Many immutable objects can be used as:

4. Easier reasoning
You don't have to worry about another function modifying the object.

5. Useful for concurrency
Immutable data is easier to share between concurrent operations
because there is no state mutation to coordinate.

## Shallow Copy  |  Deep Copy

>>> orignal = [[1,2],[3,4]]
>>> copy_new = orignal.copy()
>>> copy_new
[[1, 2], [3, 4]]
>>> id(orignal)
4562287296
>>> id(copy_new)
4562519040

>>> import copy
>>> deep_copy = copy.deepcopy(orignal)
>>> deep_copy
[[1, 2], 100]


| Operation          | Outer object | Nested objects  |
| ------------------ | ------------ | --------------- |
| Assignment `b = a` | Same         | Same            |
| Shallow copy       | New          | Same references |
| Deep copy          | New          | New recursively |

=====================

Python uses call by object sharing (often described as call by object reference).
A function receives a reference to the same object, but the local parameter is
itself a separate name. Mutating the object is visible to the caller,
while rebinding the parameter is not.
