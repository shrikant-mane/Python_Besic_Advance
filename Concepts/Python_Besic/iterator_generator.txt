what is difference between iterator and generator with example?

Iterator is an object that produces values one at a time using __iter__() and __next__().

Generator is a simple way to create an iterator using yield.

“Every generator is an iterator, but not every iterator is a generator.”

Generator ⊂ Iterator concept

## ITERATOR

>> numbers = [1,2,3,4,5]
>>> iter(numbers)
<list_iterator object at 0x10f078730>
>>> result = iter(numbers)
>>> result
<list_iterator object at 0x10f079810>
>>> next(result)
1
>>> next(result)
